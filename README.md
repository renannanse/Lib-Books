# Lib-Books
Lib Books é um leitor e gerenciador de biblioteca virtual  completo e moderno direto no navegador, compatível com os  formatos PDF, EPUB, TXT, CBZ e ZIP.Ideal para organizar,  categorizar por pastas e ler seus títulos favoritos com  suporte a temas dinâmicos, controle de marcadores e backup  em nuvem ou local.
